# Pricing — DIYChatbots

## Starter
- Price: $0/month, forever
- Limits: none imposed by DIYChatbots — no message cap, no time limit, no credit card required
- Features: all 12 industry templates, unlimited customisation, GitHub Pages hosting, knowledge base ingestion (paste text, upload documents, or reference URLs), demo mode (no AI key required to try it)
- Not included: custom domain support from DIYChatbots (bring your own via GitHub Pages), analytics dashboard, multi-bot management
- Note on cost: the only ongoing cost is optional AI usage on the business's own Anthropic API account, typically a few dollars a month for a small business; DIYChatbots itself charges nothing

## Pro
- Price: $9/month (planned; not yet available — see diychatbots.com for current status)
- Adds: analytics and conversation logs, multi-bot management, custom domain support, ticket system integrations, priority support

## Enterprise
- Price: custom — contact via https://diychatbots.com/contact.html
- Adds: white-label (no DIYChatbots branding), SSO/SAML/Azure AD, ServiceNow/Jira integration, on-premise deployment, SLA and dedicated support, custom AI model fine-tuning, GDPR/SOC 2 documentation

## What "free" actually means here

DIYChatbots does not host the chatbot on its own servers and does not charge for the generator. The business owner hosts their own generated file (free, via GitHub Pages) and pays their own AI provider (Anthropic) directly for usage. DIYChatbots is not an intermediary in that billing relationship on the Starter plan.
